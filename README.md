## ⚡ 開発実績・リポジトリ一覧

### 📊 1. [python-practice](https://github.com/tosane932/python-practice)（Webスクレイピング検証）
- **概要**: 大手ニュースサイトを対象とした、データ抽出および蓄積の技術検証プログラム。
- **実装内容**: 
  - WAFやIPブロック等のセキュリティ制約を回避するため、RSSフィードを活用した安定的なデータ取得ルートへ方針を最適化。
  - 抽出したデータをExcelへ自動保存・追記し、データの重複を常時監視・排除する重複防止ロジックを実装。

### 🕊️ 2. [puoppo_app](https://github.com/tosane932/puoppo_app)（自動世論調査＆要約システム）
- **概要**: 前作のスクレイピングロジックを発展させ、バックエンドデータベースと連携させた自動要約Webアプリケーション。
- **実装内容**:
  - データの永続化と高速化のため、テキストファイル管理から **SQLite3** を用いたリレーショナルデータベース管理へと移行。
  - RSSフィードから抽出したデータを自動で触知し、結果を出力するバックエンドシステムをスクラッチで構築。

### 📈 3. [sales_data_app](https://github.com/tosane932/sales_data_app)（ベーカリー売上管理システム）
- **概要**: 日次の販売数量をデータベースで一元管理し、売上動向の可視化とAI経営コンサルティングを融合させた現場主義のWebアプリケーション。
- **実装内容**:
  - **アーキテクチャの刷新**: 当初実装していた `openpyxl` によるExcel集計ロジックおよびデッドコード（約200行）をすべて削除し、リレーショナルデータベース（SQLite3/PostgreSQL）を用いた堅牢なシステムへ完全移行。
  - **データ構造の最適化**: `Flask-SQLAlchemy` を導入し、商品マスタ（`Product`）と日次実績（`DailySales`）を `1:N` で紐付けるリレーションを構築。集計処理をDBのクエリ（`JOIN`, `SUM`, `group_by`）側へ委ねることで処理効率を向上。
  - **非同期AI連携**: 最新の `google-genai` SDKを使用し、売上データに基づく3点の経営アドバイス生成ロジックを別モジュールに分離。さらに、入力画面では `Fetch API` を用いた非同期通信（Ajax）により、今日の日付に応じたAIの挨拶文（`/api/greeting`）を画面遷移なしで動的表示するユーザー体験を実装。
  - **安全管理の強化**: 従来コード内でハードコーディングされていた設定情報や、セキュリティリスクとなる `debug=True` の制御を、環境変数（`DATABASE_URL`, `FLASK_DEBUG`）を用いた一元管理（`config.py`）に変更し、本番環境での脆弱性を排除。

### 🌐 4. [rails_practice](https://github.com/tosane932/rails_practice)（Webアプリ本番環境デプロイ・異種デバイス同期）
- **概要**: Pythonでの開発からステップアップし、より大規模な開発に対応すべく「Ruby on Rails 8」を採用した統合Webアプリケーション。
- **実装内容**:
  - フレームワークのMVC思想およびマイグレーション規約を導入。フロントエンドには `Fetch API` を組み込み、画面遷移を伴わない非同期通信でのCRUD・データ削除機能を実装。
  - **インフラ制約の回避**: クラウドインフラ（Render無料枠）の「512MB RAM制限」に対し、アセットを事前にローカル側で処理する『ローカル・プリコンパイル』を導入。
  - **データの永続化**: サーバー再起動でデータがリセットされる「Read-only file system」の制約に対し、SQLite3データベースの配備先を特定の永続ディレクトリ（`storage/`）へバインドすることで解決。
  - モバイル実機（Xiaomi 15T）とPC環境間での、本番環境における同期および外部公開を実現。

### 🚚 5. [hiroshima-logistics-hub](https://github.com/tosane932/hiroshima-logistics-hub)（自動データハント＆静的供給システム）
- **概要**: 物流運行管理に必要な外部環境データ（気象・燃料価格・道路情報）を、メインサイトの負荷をかけずに高速供給する「データ出荷型」Webポータル。
- **実装内容**:
  - **アーキテクチャの転換**: 画面表示時の動的スクレイピングによる通信ラグを解消するため、Pythonスクリプトによる「定時ハント＆data.json出荷」方式を採用。
  - **静的供給**: GitHub Pages等での配信を想定し、Pythonバックエンドを持たない超軽量なフロントエンド構成を実現。
  - 広島県内のリアルタイム環境情報を統合出力し、現場での即時判断を支援するダッシュボード機能。
