# 🛠️ 実務未経験からのPython独学記録

こんにちは、**Tomoya Fujimoto (tosane932)** と申します。
IT業界の実務経験はなく、正真正銘の独学初心者からPythonの学習をスタートしました。

20代の時は「自分にはデスクワークは無理だ、指示待ちの仕事は嫌だ…」と諦めてしまい、学校でPCやデザインの資格を取ったにもかかわらず、まったく関係のない接客業や肉体労働ばかりしてきました。ずっと「資格の持ち腐れ」になっていることが心のどこかで悩みの種でした。

しかし、20代後半で結婚し、妻子にも恵まれて環境が変わりました。
現在はトラックドライバーとして働いていますが、Webデザイナーでは収入面での希望に沿わない現実を知り、「ならば、エンジニアやプログラマーに挑戦してみるか！」と一念発起。家で13年前から使っているノートパソコン（Lenovo G580）を開き、Pythonの勉強を始めました。

いざ緊張しながら飛び込んでみると、自分でもビックリするほど、やればやるほどプログラムやシステムが出来上がっていく面白さに衝撃を受けました。勉強が楽しくて、時間を忘れて10時間ぶっ通しでコードを書いた日もあります。エラーに叩きのめされ、それを自力で切り抜けた時の嬉しさが、今の私にとって最高の「ご褒美」です。

本業の傍ら、文字通りエラーと一人で戦い続けながら、まずは1週間で3つのシステムの骨格を仕立て上げました。
