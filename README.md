# 🛠️ 実務未経験からのPython独学記録

こんにちは、**Tomoya Fujimoto (tosane932)** と申します。
IT業界の実務経験はなくIT開発系の資格もない（基本情報技術者など）、正真正銘の独学初心者からPythonの学習をスタートしました。

20代の時は「自分にはデスクワークは無理だ、指示待ちのつまらない仕事は嫌だ…」と諦めてしまい、学校でPCやデザインの資格を取ったにもかかわらず、まったく関係のない接客業や肉体労働ばかりしてきました。ずっと「資格の持ち腐れ」になっていることが心のどこかで悩みの種でした。

しかし、20代後半で結婚し、妻子にも恵まれて環境が変わりました。
現在はトラックドライバーとして働いていますが、Webデザイナーでは収入面での希望に沿わない現実を知り、「ならば、エンジニアやプログラマーに挑戦してみるか！」と一念発起。家で13年前から使っているノートパソコン（Lenovo G580）を開き、Pythonの勉強を始めました。

いざ緊張しながら飛び込んでみると、自分でもビックリするほど、やればやるほどプログラムやシステムが出来上がっていく面白さに衝撃を受けました。勉強が楽しくて、時間を忘れて10時間ぶっ通しでコードを書いた日もあります。エラーに叩きのめされ、それを自力で切り抜けた時の嬉しさが、今の私にとって最高の「ご褒美」です。

本業の傍ら、文字通りエラーと一人で戦い続けながら、まずは1週間で3つのシステムの骨格を仕立て上げました。

## ⚡ これまでの戦闘記録

### 📊 1. [`python-practice`](https://github.com/tosane932/python-practice) （すべての原点：開発時間4日程 約20〜25時間）
* 基礎学習を並行で進めながら、大手ニュースサイトのスクレイピングに挑戦するも、鉄壁のセキュリティ（WAFやIPブロック）に何度も弾き返され、手を変え品を変え `training1` から `training17` まで泥臭く試行錯誤を繰り返した戦闘記録です。
* 最初はデータをExcelへ保存・追記し、記録が重複しないよう常時監視させながらデータを増やしていくロジックを構築。力技で突っ込むリスクを見切り、相手の公式窓口である「RSSフィード」を活用する安全ルート（C案の精神）を自力で閃き、約20〜25時間をかけて突破口を開きました。

### 🕊️ 2. [`puoppo_app`](https://github.com/tosane932/puoppo_app) （自動世論調査＆要約システム：開発時間1日 約10時間）
* 前作のスクレイピング突破ロジックから正統進化したWEBアプリです。
* トラックの運行中に「RSSフィードとAI要約を組み合わせる」ロジックを閃き、降車後、自宅の机で**10時間ぶっ通し**で一気に構築しました。前作の「Excelへの自動保存処理」を完全に撤廃し、バックエンドに **SQLite3（データベース）** を導入。すべて自動でデータを抽出・要約して結果を出力する、［とても軽くて楽で早い］スマートな自動調査システムへと跳躍させました。

### 📈 3. [`sales_data_app`](https://github.com/tosane932/sales_data_app) （ベーカリー売上高集計システム：開発時間3日程 約15時間）
* 実戦を意識し、ルートマン時代の「限られたスペースに売れ筋をどう最適配置するか」という現場感覚を可変3列ロジックに落とし込んだ、現場のための売上管理WEBシステムです。
* こちらも集中力を研ぎ澄まし、**約10時間**の猛チャージで一気に実装。openpyxlによるExcel動的制御、現場の誤操作を防ぐ徹底的なセル保護、そしてスマホ（Xiaomi 15T）との実機マルチデバイス連携までを形にしました。その後5時間をかけて完成までたどり着きました。
