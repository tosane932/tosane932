## ⚡ これまでの戦闘記録

### 📊 1. [`python-practice`](https://github.com/tosane932/python-practice) （すべての原点：開発期間4日程 約20〜25時間）
* 基礎学習を並行で進めながら、大手ニュースサイトのスクレイピングに挑戦するも、鉄壁のセキュリティ（WAFやIPブロック）に何度も弾き返され、手を変え品を変え `training1` から `training17` まで泥臭く試行錯誤を繰り返した戦闘記録です。
* 最初はデータをExcelへ保存・追記し、記録が重複しないよう常時監視させながらデータを増やしていくロジックを構築。力技で突っ込むリスクを見切り、相手の公式窓口である「RSSフィード」を活用する安全ルート（C案の精神）を自力で閃き、約20〜25時間をかけて突破口を開きました。

### 🕊️ 2. [`puoppo_app`](https://github.com/tosane932/puoppo_app) （自動世論調査＆要約システム：開発期間1日 約10時間）
* 前作のスクレイピング突破ロジックから正統進化したWEBアプリです。
* トラックの運行中に「RSSフィードとAI要約を組み合わせる」ロジックを閃き、降車後、自宅の机で**10時間ぶっ通し**で一気に構築しました。前作の「Excelへの自動保存処理」を完全に撤廃し、バックエンドに **SQLite3（データベース）** を導入。すべて自動でデータを抽出・要約して結果を出力する、［とても軽くて楽で早い］スマートな自動調査システムへと跳躍させました。

### 📈 3. [`sales_data_app`](https://github.com/tosane932/sales_data_app) （ベーカリー売上高集計システム：開発期間3日程 約15時間）
* 実戦を意識し、ルートマン時代の「限られたスペースに売れ筋をどう最適配置するか」という現場感覚を可変3列ロジックに落とし込んだ、現場のための売上管理WEBシステムです。
* こちらも集中力を研ぎ澄まし、**約10時間**の猛チャージで一気に実装。openpyxlによるExcel動的制御、現場の誤操作を防ぐ徹底的なセル保護、そしてスマホ（Xiaomi 15T）との実機マルチデバイス連携までを形にしました。その後5時間をかけて完成までたどり着きました。

徹底的なセル保護、そしてスマホ（Xiaomi 15T）との実機マルチデバイス連携までを形にしました。その後5時間をかけて完成までたどり着きました。

### 🌐 4. [rails_practice](https://github.com/tosane932/rails_practice) （Webアプリ本番環境デプロイ：開発期間4日程 約20時間）

* Pythonでの開発基盤からさらにステップアップし、Web開発で広く使われるフレームワーク「Ruby on Rails 8」の設計思想（MVCおよびマイグレーションによる規約重視の開発）を取り入れたWebアプリケーションの開発実績です。
* 前作までの手動ロジック構築から、フレームワークの機能をフル活用した効率的な開発へと移行。Scaffoldによる迅速な雛形生成、確実なデータ管理、さらにフロントエンドには `Fetch API` を組み込んだ非同期通信による、実用性を重視したUI設計を行いました。
* 最大の課題は、デプロイ先（Render無料枠）における「512MB RAM制限」および「Read-only file system」という環境制約への対応でした。これに対し、アセットをローカル側で事前に処理する**『ローカル・プリコンパイル』**の実施、および動的データを適切なディレクトリへ逃がす**『storage/配備』**の設計を自力で導き出し、制限をクリア。PCと実機（Xiaomi 15T）間での本番環境におけるCRUD同期および外部公開を、数日間の集中開発で安定して実現させました。
