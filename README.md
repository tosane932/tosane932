## ⚡ 開発実績・リポジトリ一覧

### 📊 1. [python-practice](https://github.com/tosane932/python-practice)（Webスクレイピング検証）
- **概要**: 大手ニュースサイトを対象とした、データ抽出および蓄積の技術検証プログラム。
- **実装内容**: 
  - WAFやIPブロック等のセキュリティ制約を回避するため、RSSフィードを活用した安定的なデータ取得ルートへ方針を最適化。
  - 抽出したデータをExcelへ自動保存・追記し、データの重複を常時監視・排除する重複防止ロジックを実装。

### 🕊️ 2. [puoppo_app](https://github.com/tosane932/puoppo_app)（自動世論調査＆要約システム）
- **概要**: 前作のスクレイピングロジックを発展させ、バックエンドデータベースと連携させた自動要約Webアプリケーション。
- **実装内容**:
  - データの永続化と高速化のため、テキストファイル管理から **SQLite3** を用いたリレーショナルデータベース管理へと移行。
  - 10時間の集中開発により、RSSフィードから抽出したデータを自動で抽出し、結果を素早く出力する軽量かつ高速なバックエンドシステムをスクラッチで構築。

### 📈 3. [sales_data_app](https://github.com/tosane932/sales_data_app)（ベーカリー売上高集計システム）
- **概要**: ルートマン時代の「限られたスペースにおける商品配置の最適化」を可変3列ロジックとして落とし込んだ、現場主義の売上管理Webアプリケーション。
- **実装内容**:
  - `openpyxl` を用いたExcelデータの動的制御。現場での誤操作を防ぐための徹底的なセル保護機能を実装。
  - スマートフォン（Xiaomi 15T）とのマルチデバイスUI連携を検証し、現場での即時入力に耐えうる実用的なインターフェースを確立。

### 🌐 4. [rails_practice](https://github.com/tosane932/rails_practice)（Webアプリ本番環境デプロイ・異種デバイス同期）
- **概要**: Pythonでの開発からステップアップし、より大規模な開発に対応すべく「Ruby on Rails 8」を採用した統合Webアプリケーション。
- **実装内容**:
  - フレームワークのMVC思想およびマイグレーション規約を導入。フロントエンドには `Fetch API` を組み込み、画面遷移を伴わない非同期通信でのCRUD・データ削除機能を実装。
  - **インフラ制約の回避**: クラウドインフラ（Render無料枠）の「512MB RAM制限」に対し、アセットを事前にローカル側で処理する**『ローカル・プリコンパイル』**を導入。
  - **データの永続化**: サーバー再起動でデータがリセットされる「Read-only file system」の制約に対し、SQLite3データベースの配備先を特定の永続ディレクトリ（`storage/`）へバインドすることで完全解決。
  - モバイル実機（Xiaomi 15T）とPC環境間での、本番環境における完全同期および外部公開を数日間の集中開発で実現。
